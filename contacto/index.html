Soporte de DineroMundo

Correo monitoreado: amcykarimgroupinc@gmail.com. Puedes reportar errores técnicos, enlaces rotos, problemas con tu cuenta o información desactualizada. Incluye la URL y una descripción concreta, pero nunca envíes contraseñas, códigos de acceso ni datos financieros completos.

Para solicitar la eliminación de una cuenta, escribe desde el mismo correo registrado y usa el asunto Eliminar mi cuenta DineroMundo. Consulta el proceso de eliminación.

Información que no debes enviar

No envíes nombres completos innecesarios, números de cuentas financieras, tarjetas, Seguro Social, ITIN, contraseñas, códigos de seguridad, direcciones, documentos de identidad ni capturas que los muestren. DineroMundo no necesita esos datos para revisar contenido o un error técnico.

Transferencias y cuentas

DineroMundo no procesa, rastrea, cancela ni reembolsa transferencias. Para una operación específica, utiliza los canales oficiales del proveedor o institución. No publiques aquí números completos de referencia ni información del destinatario.

Correcciones editoriales

Los reportes verificables se evaluarán conforme a nuestra política de correcciones. La ausencia temporal de contacto directo no cambia la recomendación de verificar información financiera actual con una fuente oficial.
