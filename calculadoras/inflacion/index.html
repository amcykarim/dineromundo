Cómo funciona

El costo futuro multiplica el importe por uno más la tasa elevada al número de años. El poder adquisitivo aplica el proceso inverso.

El resultado sirve para explorar escenarios con los datos que ingresas. Puedes ajustar una cifra, volver a calcular y comparar cómo cambia el resultado sin enviar información a ningún servidor.

Ejemplo práctico

Con 3% anual, algo que cuesta $100 hoy tendría un costo matemático aproximado de $115.93 dentro de cinco años. Este ejemplo es ilustrativo: utiliza tus propios datos para obtener una estimación relevante.

Cómo usar la calculadora

  1. Completa todos los campos obligatorios con valores no negativos.
  2. Selecciona la moneda únicamente para cambiar el formato.
  3. Presiona “Calcular”, revisa los resultados y ajusta los datos si deseas comparar escenarios.

Consideraciones importantes

La tasa de inflación la introduce el visitante y no constituye una predicción. La inflación real cambia con el tiempo y según la categoría.

Preguntas frecuentes

¿La tasa es una predicción?

No. Es un supuesto elegido por ti para explorar escenarios.

¿Qué significa poder adquisitivo?

Es una estimación de cuánto podría comprar en el futuro la cantidad actual.

¿Puedo ingresar una tasa decimal?

Sí. Por ejemplo, puedes usar 2.5%.
