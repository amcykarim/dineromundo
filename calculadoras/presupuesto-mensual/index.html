Cómo funciona

La herramienta resta del ingreso neto la suma de vivienda, servicios, alimentación, transporte, seguros, deudas, ahorro, entretenimiento y otros gastos. Los porcentajes se calculan respecto al ingreso mensual.

El resultado sirve para explorar escenarios con los datos que ingresas. Puedes ajustar una cifra, volver a calcular y comparar cómo cambia el resultado sin enviar información a ningún servidor.

Ejemplo práctico

Si ingresas $3,000 y tus gastos suman $2,550, el resultado muestra $450 disponibles y 85% del ingreso utilizado. Este ejemplo es ilustrativo: utiliza tus propios datos para obtener una estimación relevante.

Cómo usar la calculadora

  1. Completa todos los campos obligatorios con valores no negativos.
  2. Selecciona la moneda únicamente para cambiar el formato.
  3. Presiona “Calcular”, revisa los resultados y ajusta los datos si deseas comparar escenarios.

Consideraciones importantes

Incluye gastos irregulares como un promedio mensual. Un resultado positivo no sustituye un plan financiero y un resultado negativo es una señal para revisar categorías.

Preguntas frecuentes

¿Debo usar ingresos brutos o netos?

Usa el dinero que realmente recibes después de deducciones.

¿El ahorro cuenta como gasto?

Aquí se incluye como una asignación mensual para mostrar cuánto dinero ya tiene un propósito.

¿Qué pongo en otros gastos?

Incluye suscripciones, cuidado personal y gastos que no encajen en otra categoría.
